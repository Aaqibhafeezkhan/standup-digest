# Contributing to standup-digest

Thanks for helping! Small, clear contributions are the best ones.

## Easy ways to start

- Pick an issue labelled **good first issue** and comment that you are taking it.
- Try the Quick start in the README and tell us what was confusing. Fixing the README counts as a real contribution.
- Share a Google Form setup that did not work, with the question titles (no private answers).

## Making a change

1. Fork the repository.
2. Make your change in your copy (the GitHub website editor is fine).
3. Open a pull request and say what you changed and why. Link the issue ("Closes #3").

## Guidelines

- Keep it free and simple: no paid services needed for the core tool.
- Do not commit real emails, names, or answers from real teams.
- Explain things in plain language. Many users are not developers.

## Be kind

Everyone here is learning. Be patient and respectful in issues and reviews.
